# FreeWar2
Free open source game engine for running Warcraft 2. It requieres the game files from cd version

# Prerequisites

    -Windows
    MonoGame: 3.6 or higher
    OpenAL 2.0
    
    -Linux
    OpenGL 3.0
    SDL2 

# Build

Use Visual Studio 2017 or higher. Mono for Linux. Run FreeWar2.sln to build
